Recipe SQL Data Insertion SchemaThis document outlines the exact format required for SQL scripts that insert new recipes into the database. Following this schema ensures data consistency and compatibility with the application's frontend and backend.1. Table StructureThe recipes table is defined with the following columns and data types.CREATE TABLE IF NOT EXISTS recipes (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  tags TEXT,
  ingredients TEXT,
  instructions TEXT
);
2. SQL Insert Script FormatAll new recipe data must be provided in an SQL script that adheres to the following structure and formatting rules.2.1. File PreambleThe script should begin with a comment block explaining its purpose and a DELETE statement to ensure the script is idempotent (can be run multiple times without causing errors).-- This script first DELETES any existing recipes within a specific ID range to prevent conflicts,
-- then INSERTS the new, corrected versions.
-- To escape a single quote (') in the text, it has been replaced with two single quotes ('').

DELETE FROM recipes WHERE id >= [START_ID];
2.2. Individual Recipe Entry FormatEach recipe must be inserted using the following multi-line format.Comment Header: Each INSERT statement must be preceded by a comment identifying the recipe number (e.g., -- ========== RECIPE 77 ==========).Column Order: The INSERT statement must specify the columns in this exact order: (id, name, tags, ingredients, instructions).Data Formatting:id (INTEGER): The unique recipe number.name (TEXT): The recipe title, enclosed in single quotes.tags (TEXT): A single string of comma-separated values, enclosed in single quotes. Do not use a JSON array.ingredients (TEXT): A JSON string, enclosed in single quotes. The JSON should be formatted with indentation for readability.instructions (TEXT): A JSON array of strings, enclosed in single quotes. The JSON should be formatted with indentation for readability.2.3. Example TemplateThis example demonstrates the exact formatting required for a single recipe entry.-- ========== RECIPE 77 ==========
